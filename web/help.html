Camera setup

Back to the profiler

What you need

  • A Thorlabs Zelux CS165MU or CS165CU camera on a USB 3 port.
  • Chrome or Edge on a desktop computer. Firefox and Safari have no WebUSB.
  • Nothing else: no ThorCam, no Thorlabs SDK, no DLL. The page drives the camera itself.

Windows: give the camera the WinUSB driver (once per computer)

Windows lets one driver own a USB device. ThorCam installs the Thorlabs driver (CYUSB3), which a browser cannot use. The browser needs Microsoft's generic WinUSB driver instead.

  1. Close ThorCam and any other program that uses the camera, and plug the camera in.
  2. Download Zadig (free, from its official site) and run it.
  3. Menu Options → tick List All Devices.
  4. Pick the device TSI (USB ID 1313 4002). Check the USB ID: choosing another device would replace that device's driver.
  5. Set the target driver to WinUSB and press Replace Driver.
  6. Unplug and replug the camera.

While the camera uses WinUSB, ThorCam and the Thorlabs SDK (including LabVIEW and the desktop version of this profiler) cannot see it. Each camera works with one or the other at a time.

Switching back to ThorCam

  1. Open Device Manager, find the camera (under Universal Serial Bus devices, named TSI).
  2. Right-click → Uninstall device, tick Attempt to remove the driver for this device, and confirm.
  3. Unplug and replug the camera: Windows installs the Thorlabs driver again. If it does not, reinstall ThorCam.

Linux, macOS, ChromeOS

No driver swap is needed. On Linux, give your user access to the device, for example with a udev rule SUBSYSTEM=="usb", ATTR{idVendor}=="1313", ATTR{idProduct}=="4002", MODE="0666" in /etc/udev/rules.d/50-zelux.rules, then replug. These systems are untested.

Connecting

  1. Open the profiler and press Connect camera. The browser asks which device to allow; pick the camera.
  2. From then on the page finds the camera by itself: when the page opens, and when the camera is plugged in.
  3. To revoke the permission, click the site-settings icon left of the address bar.

Troubleshooting

  • The camera does not appear in the chooser: it still has the Thorlabs driver (see above), or the page is not opened over https://.
  • "Unable to claim interface" / access denied: another program or browser tab has the camera open. Close it and try again.
  • Low frame rate: use a USB 3 port directly on the computer. Full frames are about 2 MB, so 35 frames per second need about 70 MB/s.

How it works

The camera speaks plain-text commands (exp 5000, gain 0, arm, start) over one USB endpoint and streams 10-bit packed image data over another. This page sends those commands with WebUSB and decodes the frames itself. The beam analysis (Gaussian fit, 1/e² diameters, second moments, auto-zoom) is the same Rust code as the desktop profiler, compiled to WebAssembly. Nothing is uploaded: all processing happens in this browser.
